01
Classic Design Style

Skeuomorphism

UI elements that mimic real-world objects — stitched leather, brushed metal, worn paper. Dominant in iOS 6 era, it made digital feel tactile and familiar.

Key Characteristics
Realistic textures — leather, wood, metal, paper surfaces
Deep drop shadows — multi-layered, directional light sources
Bevels & embossing — raised / inset to simulate depth
Stitching, rivets — decorative mimicry of real materials
Rich gradients — 8–12 stop gradients for material feel
CSS Snippet — Skeuomorphic Button
.skeu-btn { background: linear-gradient(180deg, #7ab550, #3a6010); box-shadow: 0 1px 0 rgba(255,255,255,.25) inset, 0 -1px 0 rgba(0,0,0,.3) inset, 0 4px 8px rgba(0,0,0,.5); border: none; text-shadow: 0 1px 1px rgba(0,0,0,.4); }
✅ Use When

Building audio/music apps, finance tools, or instruments where physical metaphors reduce learning curve. Perfect for products targeting non-tech users.

Real-World Examples
iOS 6 Calendar GarageBand (2010) Find My Friends Kindle App Old Winamp

Modern Soft UI

Neumorphism

Elements appear extruded from the background using dual shadows — one light, one dark — giving a soft 3D molded effect. Also called "Soft UI".

Key Characteristics
Monochrome palette — elements share background color ±15% lightness
Dual shadows — one light (top-left) + one dark (bottom-right)
Inset for pressed — active state reverses the shadows inward
No harsh borders — borders are replaced by shadow illusion
Subtle pop accents — single accent color for progress/active states
CSS Snippet — Neumorphic Card
.neu-card { background: #e0e5ec; /* SAME as body bg */ box-shadow: 9px 9px 18px #b8bec9, /* dark shadow ↘ */ -9px -9px 18px #ffffff; /* light shadow ↖ */ border-radius: 20px; } .pressed { /* inset = active */ box-shadow: inset 4px 4px 8px #b8bec9, inset -4px -4px 8px #ffffff; }
✅ Use When

Building dashboards, health/wellness apps, music players with a premium, tactile feel. ⚠️ Poor accessibility — low contrast. Always pair with strong color on key actions.

Real-World Examples
Dribbble shots 2020 Banking dashboards Smart home controls Health apps

Frosted Glass Aesthetic

Glassmorphism

UI panels that look like frosted glass — translucent backgrounds, blur effects, and subtle borders that create layered depth. Popularized by macOS Big Sur.

Key Characteristics
backdrop-filter: blur() — the core CSS property (8–30px range)
Low opacity background — rgba(255,255,255,.08–.15)
Thin border highlight — 1px rgba(255,255,255,.18) on top-left
Colorful background — needs vibrant gradient/image behind panel
Soft shadow beneath — grounding the floating panel
CSS Snippet — Glass Panel
.glass-card { background: rgba(255, 255, 255, 0.1); backdrop-filter: blur(20px) saturate(180%); -webkit-backdrop-filter: blur(20px); border: 1px solid rgba(255,255,255,0.18); box-shadow: 0 8px 32px rgba(0,0,0,0.3), inset 0 1px 0 rgba(255,255,255,0.25); }
✅ Use When

Landing pages, profile cards, notification panels, popups over rich backgrounds. ⚠️ Expensive on GPU — avoid on cards that animate rapidly or appear in long lists.

04
Less is More

Minimalism

Strip every element to its essential function. Radical whitespace, tight typography, and a single accent. Every pixel earns its place.

Design Guide 2025
Think.
Less.

Eliminate the unnecessary. Let breathing room do the work your decorations cannot.

Key Characteristics
Extreme whitespace — 60–80% of the screen can be empty
Limited palette — typically 2 colors max (black + one accent)
Typography as hero — font choice carries all the personality
Flat design — no shadows, no gradients, no decorations
Functional clarity — the purpose of every element is immediately clear
CSS Snippet — Minimal Button
.min-btn { background: #111; color: #fff; border: none; border-radius: 2px; /* almost no rounding */ padding: 12px 28px; font-size: .78rem; letter-spacing: .08em; text-transform: uppercase; /* No box-shadow. No gradient. Pure. */ }
✅ Use When

Portfolios, editorial sites, luxury brands, B2B SaaS dashboards, and any product where cognitive clarity and focus are paramount. Great first choice for intern projects.

Real-World Examples
Apple.com Linear.app Notion Google Search Medium

06
Raw & Unpolished

Brutalism

Intentionally raw, anti-design. Hard borders, no border-radius, stark black/white contrast with acid accents. Inspired by brutalist architecture — expose the structure.

NEW
Design
Is War.

Rules exist to be understood before they're broken. This is CSS that doesn't apologize.

06
Key Characteristics
Solid 2–4px borders — hard black outlines everywhere
Offset box shadows — 4–8px solid (no blur) creates flat offset shadow
Zero border-radius — or 0px/2px max — sharp corners always
Monospace or slab fonts — Courier, Courier New, or wide display
Acid accent on dark/white — yellow, neon green, red on pure black or white
CSS Snippet — Brutalist Button
.brut-btn { border: 3px solid #000; border-radius: 0; /* zero radius */ box-shadow: 4px 4px 0 #000; /* flat offset */ background: #000; color: #f5f000; /* acid yellow */ transition: transform .1s, box-shadow .1s; } .brut-btn:hover { transform: translate(4px, 4px); box-shadow: 0 0 0 #000; }
✅ Use When

Creative agencies, indie games, music labels, developer tools (like AediaX!), personal portfolios that want to stand out. Extremely memorable and trendy right now.

Real-World Examples
Figma.com (2019) Cargo.site Bloomberg.com Balenciaga

Key Characteristics
Ambient color sampling — background colors bleed through dynamically
High saturation blur — backdrop-filter with high saturate() values
Full pill shapes — border-radius: 100px — everything is a lozenge
1px specular highlight — inset 0 1px 0 rgba(255,255,255,.3)
Animated light orbs — floating radial gradients behind the glass
CSS Snippet — Liquid Glass Bar
.lg-bar { background: rgba(255,255,255,.06); backdrop-filter: blur(40px) saturate(200%) brightness(1.3); border: 1px solid rgba(255,255,255,.18); border-radius: 100px; /* full pill */ box-shadow: inset 0 1px 0 rgba(255,255,255,.25), 0 4px 20px rgba(0,0,0,.3); }
✅ Use When

iOS/macOS-style apps, visionOS interfaces, notification/widget systems. This is the dominant design language of 2025. Use for modern app UIs targeting Apple ecosystem.

Key Characteristics
CSS Grid with spans — grid-column: span 2; grid-row: span 2
Card-based composition — each cell is self-contained, rounded (10–20px)
Consistent gap — 8–12px gap between all cells
Visual hierarchy — big cells = important data, small cells = status
Dark substrate — dark background makes colored cells pop
CSS Snippet — Bento Grid
.bento-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; } .big-cell { grid-column: span 2; } .tall-cell { grid-row: span 2; } .hero-cell { grid-column: 1 / -1; /* full width */ }
✅ Use When

Dashboards, landing pages feature sections, Apple-style product event pages, analytics interfaces. Great for AediaX intern dashboard projects!

Key Characteristics
CSS perspective — parent gets perspective: 800px, children use rotateX/Y
Transform Z-layers — translateZ() separates elements in 3D space
Deep layered shadows — 30–80px blur with low opacity creates air under cards
Specular light — inset highlight simulates light hitting a surface
Floating elements — elements appear to hover above the surface
CSS Snippet — Spatial Card
.spatial-parent { perspective: 800px; transform-style: preserve-3d; } .spatial-card { transform: rotateX(8deg) rotateY(-6deg); box-shadow: 0 30px 80px rgba(0,0,0,.6), 0 10px 30px rgba(0,0,0,.4); } .icon { transform: translateZ(12px); }
✅ Use When

VR/AR app UIs, product showcases, hero sections, game HUDs. Use for the Cortexy AI landing page or any AediaX product that wants a next-gen feel.

3D Inflated Clay Elements

Claymorphism

UI elements that look like chunky, inflated clay toys — puffy 3D shapes with soft gradients, thick pastel borders, and a distinct bottom shadow that gives depth.

🎨
Design Studio
3 active projects
💖 Design
✅ Done
🔮 Draft
Key Characteristics
Offset bottom shadow — 0 4px 0 (color) + 0 6px 12px rgba — creates the "clay block" feel
Inset white highlight — 0 1px 0 rgba(255,255,255,.8) inside top edge
Pastel palette — soft pinks, mints, lavenders, yellows — never harsh
Large border-radius — 16–24px, everything is rounded and puffy
Press animation — translateY(4px) + remove bottom shadow on click
CSS Snippet — Clay Button
.clay-btn { border-radius: 14px; border: 3px solid rgba(0,0,0,.08); box-shadow: 0 1px 0 rgba(255,255,255,.7) inset, /* highlight */ 0 4px 0 #6d28d9, /* clay depth */ 0 6px 12px rgba(0,0,0,.15); /* soft shadow */ } .clay-btn:active { transform: translateY(4px); box-shadow: inset 0 1px 0 rgba(255,255,255,.7); }
✅ Use When

Kids apps, education platforms, productivity tools targeting Gen-Z, mobile apps that want a playful premium feel. Perfect for AediaX intern projects with a fun angle.
